# Ceph official documentation catalog

This catalog is metadata only; live cluster evidence always wins over a
documentation hit. The versions match the natural-language tool registry's
supported major-release codenames and must be re-verified before a release.

| Major release | Official documentation | Retrieval policy |
| --- | --- | --- |
| Reef (18) | https://docs.ceph.com/en/reef/ | version-filtered |
| Squid (19) | https://docs.ceph.com/en/squid/ | version-filtered |
| Tentacle (20) | https://docs.ceph.com/en/tentacle/ | version-filtered |

Only public official Ceph documentation is eligible for this catalog. No
credentials, private deployment logs, or unverified operator text may be
ingested as official documentation. A version mismatch is fail-closed and
returns no incompatible hit.
